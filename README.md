## Cách đăng trang này lên GitHub Pages (0đ)

1. Tạo repository mới trên GitHub (ví dụ: `link-in-bio`).
2. Đẩy toàn bộ nội dung thư mục này (gồm `index.html`, `README.md`, `assets/`) lên repository.
3. Vào **Settings → Pages → Build and deployment → Source: Deploy from a branch**, chọn nhánh `main`, thư mục `/ (root)`.
4. Trang sẽ chạy tại `https://<username>.github.io/<repo>/`. Dán link này vào bio TikTok / Instagram / Facebook / mô tả YouTube.
